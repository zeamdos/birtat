Gesture recognition uses MediaPipe Tasks Vision 1.2.3 (Apache 2.0),
from https://www.npmjs.com/package/@mediapipe/tasks-vision.
The Apache 2.0 license text is included in LICENSE.

The pretrained gesture model comes from Google's MediaPipe model distribution:
https://storage.googleapis.com/mediapipe-models/gesture_recognizer/gesture_recognizer/float16/1/gesture_recognizer.task

The runtime and model run in the browser. Camera frames are not uploaded.
The built-in classifier recognizes a small set of common poses; it is not an
Ethiopian Sign Language translator.
